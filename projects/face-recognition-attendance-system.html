Face Recognition Attendance System

Laravel 10 + Python 3.10 · Individual Project · 12 February 2025 – 3 June 2026

This project is created to replace manual employee attendance on PT.Abadi Nyon to be automatic attendance system. This project had built-in face recognition using Python program with version 3.10, This project had CRUD features for employee list, attendance reports, and salary management that automatically counted by system using each employee attendance records.

What I did

  • Built the web application with Laravel 10
  • Build and integrated the Python face recognition model using Python v3.10
  • Attendance reports
  • Employee management (CRUD)
  • Salary that integrated with employees attendance records
